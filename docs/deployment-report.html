📦 گزارش مخزن گیت‌هاب و فایل‌های لازم برای دیپلوی — فروشگاه «یک دوست»

پاسخ به این سؤال که «چرا ۹۰٪ کد گیت‌هاب ما HTML است؟» + فهرست دقیق پوشه‌ها و صفحاتی که در استقرار (Deploy) لازم نیستند.

به‌روزرسانی: اسفند ۱۴۰۴ · اندازه‌ها از خود مخزن (git) اندازه‌گیری شده

۱) چرا گیت‌هاب می‌گوید پروژه ۹۰٪ HTML است؟

نوار زبان گیت‌هاب (Language Bar) درصد هر زبان را از «حجم بایت‌ها» حساب می‌کند، نه تعداد فایل‌ها. کل مخزن ≈ ۳۸ مگابایت است و از این مقدار:

public/pages/ — ۳۲ صفحه‌ی HTML دموی قدیمی ≈ ۱۷٫۳MB upload/ — ۲ فایل باندل اصلی طراحی ≈ ۱۶٫۶MB tool-results/ ≈ ۱٫۵MB src/ — کد واقعی برنامه ≈ ۱٫۳MB بقیه (پیکربندی، اسکریپت‌ها، مستندات) ≈ ۱٫۳MB
پس: بله، حدس شما درست است. تعداد فایل‌های HTML فقط ۳۷ عدد از ۲۹۹ فایل است (≈ ۱۲٪)؛ ولی چون حجم‌شان حدود ۳۴ مگابایت از ۳۸ مگابایت مخزن را گرفته (۲ فایل باندل طراحی ۱۶٫۶MB + ۳۲ صفحه‌ی دموی self-contained در public/pages/ با ۱۷٫۳MB)، نمودار زبان گیت‌هاب ≈ ۹۰٪ HTML نشان می‌دهد. کد واقعی فروشگاه (TypeScript در src/) فقط ۱٫۳ مگابایت است.

۲) پوشه‌ی public/page/ چیست؟ آیا در سایت استفاده می‌شود؟

  • پوشه‌ای به نام public/page وجود ندارد؛ چیزی که هست public/pages/ است.
  • این پوشه ۳۲ صفحه‌ی HTML خودکفا (self-contained) است که در ابتدای پروژه از دو فایل باندلِ طراحی («پیشتم — وباپ هدیه‌ی دوستانه») استخراج شد تا دموی طراحی مرور شود. فروشگاه فعلی هیچ‌جای خودش از این صفحات استفاده نمی‌کند — تنها رفرنس‌های آن‌ها در کامپوننت‌های گالری قدیمی (src/components/pishnam/*، src/data/pages.ts و ۳ هوک use-recent/notes/favorite-pages) است که خودشان هم دیگر از هیچ صفحه‌ای import نمی‌شوند (کد مرده).
  • چون داخل public/ است، در هر بیلد و دیپلوی کپی و منتشر می‌شود — یعنی ≈ ۱۷٫۳ مگابایت بار اضافه روی بیلد، بدون هیچ استفاده‌ای.
  • سه فایل public/pishnam-architecture.html، public/pishnam-docs.html و public/pishnam-prescription.html هم مستندات داخلی هستند که به‌اشتباه داخل public منتشر می‌شوند.

۳) فهرست نهایی: چه چیزی در دیپلوی لازم نیست؟

git rm -r --cached public/pages upload tool-results
git rm -r --cached src/components/pishnam src/data/pages.ts
git rm -r --cached src/hooks/use-favorite-pages.ts src/hooks/use-page-notes.ts src/hooks/use-recent-pages.ts
git mv public/pishnam-architecture.html public/pishnam-docs.html public/pishnam-prescription.html docs/
printf '\n# design-demo leftovers & agent logs\ntool-results/\n' >> .gitignore
git commit -m "chore: remove design-demo pages and agent logs from repo"

۴) در دیپلوی (Netlify) واقعاً چه چیزی مصرف می‌شود؟

  • کد سرور و صفحات: src/ → کامپایل به .next/ (خروجی standalone + توابع API).
  • دیتابیس: فایل db/custom.db در گیت نیست؛ فرمان بیلد در netlify.toml خودش دیتابیس تازه می‌سازد و seed می‌کند (prisma generate → db push → seed-commerce → seed-blog).
  • فایل‌های عمومی: کل پوشه‌ی public/ عیناً منتشر می‌شود — به همین دلیل public/pages/ هم اکنون در yekdoost.netlify.app/pages/main.html قابل بازشدن است ولی هیچ لینکی به آن‌ها نیست.
  • رسانه‌های داینامیک (عکس افزودنی‌ها، رسیدها، پیام‌ها): روی فایل‌سیستم نمونه (/tmp/.data) ذخیره می‌شوند و به گیت ربطی ندارند.
  • رمزها: همه در Environment Variables سرویس استقرار؛ .env در گیت نیست.
